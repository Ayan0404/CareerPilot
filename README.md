# CareerPilot 🚀

### Your career journey starts here.

CareerPilot is a personal web development project designed to help students discover technology spring-week opportunities and explore potential career paths in the tech industry.

The website provides a simple landing page that directs users to LinkTrackr's UK Technology Spring Weeks page, where they can explore available opportunities.

## 🎯 Project Goals

- Build a clean and modern landing page.
- Make technology spring-week opportunities easier for students to discover.
- Practise front-end web development using HTML and CSS.
- Learn how to structure a website and style its components.

## 🛠️ Technologies Used

- **HTML5** — Structured the webpage using headings, paragraphs, links, a header, main content and a footer.
- **CSS3** — Styled the page with colours, gradients, typography, spacing, rounded corners, shadows and hover effects.
- **Google Fonts** — Used the Manrope typeface for a modern appearance.
- **Git & GitHub** — Used for version control and project sharing.

## ✨ Features

- A branded CareerPilot header.
- An introduction explaining the purpose of the website.
- A call-to-action button linking to LinkTrackr's UK Tech Spring Weeks page.
- A modern dark theme with purple and blue gradients.
- Interactive button hover effects.
- A simple footer with project branding.

## 💡 What I Learned

While developing CareerPilot, I practised:

- Creating the structure of a webpage with HTML.
- Connecting an external CSS stylesheet to HTML.
- Using CSS classes and selectors to style specific elements.
- Applying gradients, typography and hover transitions.
- Linking to an external website safely using `target="_blank"` and `rel="noopener noreferrer"`.
- Using GitHub to share and manage a project.
- Using AI-assisted guidance to understand code and improve the design.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser.
4. Make sure the CSS filename matches the stylesheet link in the HTML file.

An internet connection is required to load the Google Font.
